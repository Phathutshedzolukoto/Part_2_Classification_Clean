1. Introduction and Objectives¶

Classification is a supervised machine-learning task that predicts a category from labelled examples. This project explores whether numerical measurements of breast tumours can be used to classify cases as benign (B) or malignant (M).

Objectives:

  • Load and inspect the dataset.
  • Check data quality and clean irrelevant columns.
  • Explore the target classes and selected numerical features.
  • Train a baseline Random Forest Classifier.
  • test a second parameter configuration and compare both models.
  • Evaluate predictions using multiple metrics and confusion matrices.
  • Discuss findings, limitations and recommendations.

This is an educational exercise, not a clinical diagnostic system.

2. Dataset Selection and Justification¶

This project uses the Breast Cancer Wisconsin (Diagnostic) dataset available from Kaggle: https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

The dataset contains numerical measurements and a labelled target column, diagnosis, with benign (B) and malignant (M) classes. This makes it suitable for a supervised binary classification task. Save the downloaded CSV as data.csv in the same folder as this notebook, or change the filename in Section 5.

3. Algorithm Selection: Random Forest¶

A Random Forest Classifier combines predictions from multiple decision trees. It can model non-linear relationships, works with numerical predictors, and provides feature-importance estimates. These properties make it a reasonable algorithm for this classification exercise.

Feature importance does not prove causation, and good test performance does not establish clinical validity. The model must not be used as a substitute for medical advice or diagnosis.

13. Improve the Random Forest Model¶

The second model uses more trees and limits tree depth and minimum leaf sizes. Class weighting is also enabled. These settings are an experiment, not a guarantee of better performance. Ideally, parameter selection would use cross-validation on training data; avoid repeatedly tuning against the held-out test set.

In [16]:
improved_model = RandomForestClassifier(

    max_depth=10,
    min_samples_split=4,
    min_samples_leaf=2,
    random_state=RANDOM_STATE,
    class_weight="balanced"
